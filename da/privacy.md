# Privatliv

<p class="lead">Kort sagt: alt, hvad Nyvo gemmer, bliver på dit tv. Der er ingen Nyvo-server, ingen konto hos os og ingen statistik over, hvordan du bruger appen.</p>

## Det gemmes, på dit tv

| Hvad | Hvorfor |
|---|---|
| Dine kontooplysninger (server, brugernavn og adgangskode eller adressen til playlisten) | For at logge ind hos din udbyder. De gemmes **krypteret** med en nøgle, der oprettes på tv'et og ikke kan læses ud. |
| Udvalget og tv-guiden | Så lister og guide vises hurtigt uden at blive hentet hver gang |
| Favoritter, hvor du nåede til og dine indstillinger | Så appen husker dine valg |
| Pinkoden til forældrekontrol og låste kategorier | For at beskytte indhold |

**Log ud** under *Indstillinger → Konto* fjerner kontoen og alle gemte data fra tv'et.

## Det sendes, og hvorhen

- **Til din udbyder:** login, hentning af udvalget og tv-guiden og de streams, du ser. Udbyderen behandler dem efter sine egne vilkår.
- **Til adresser, du selv angiver** (playliste og tv-guide).
- **Intet til Nyvo** eller andre: ingen statistik, ingen reklamer, ingen sporing.

## Dette websted

Webstedet ligger på GitHub Pages og bruger ingen cookies eller analyseværktøjer. GitHub kan logge besøg i henhold til [GitHubs privatlivserklæring](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Indhold

Nyvo indeholder ingen tv-kanaler, film eller serier og sælger ingen abonnementer. Alt, hvad du ser, kommer fra din egen udbyder.
