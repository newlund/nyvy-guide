# nyvo-guide

User manual, support page and privacy policy for **Nyvo**, an IPTV player for LG webOS TVs.
Published with GitHub Pages at <https://newlund.github.io/nyvo-guide/> (Swedish and English).

- `sv/` and `en/`: the pages, in Markdown (`manual`, `stod`/`support`, `integritet`/`privacy`).
- `_layouts/default.html` and `assets/style.css`: the shared look.
- Support: Buy Me a Coffee (<https://buymeacoffee.com/nyvo>). A Ko-fi button is prepared as a comment in `sv/stod.md` and `en/support.md`.
- `node preview.mjs` renders a local preview into `_preview/` (no Jekyll needed).

The Nyvo app links here from *Settings → About* with a QR code.
