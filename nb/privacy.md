# Personvern

<p class="lead">Kort sagt: alt Nyvy lagrer, blir på TV-en din. Det finnes ingen Nyvy-server, ingen konto hos oss og ingen statistikk over hvordan du bruker appen.</p>

## Dette lagres, på TV-en din

| Hva | Hvorfor |
|---|---|
| Kontoopplysningene dine (server, brukernavn og passord, eller adressen til spillelisten) | For å logge inn hos leverandøren din. De lagres **kryptert** med en nøkkel som lages på TV-en og ikke kan leses ut. |
| Utvalget og TV-guiden | Så lister og guide vises raskt uten å hentes hver gang |
| Favoritter, hvor du slapp og innstillingene dine | Så appen husker valgene dine |
| PIN-koden for foreldrekontroll og låste kategorier | For å beskytte innhold |

**Logg ut** under *Innstillinger → Konto* fjerner kontoen og alle lagrede data fra TV-en.

## Dette sendes, og hvor

- **Til leverandøren din:** innloggingen, nedlastingen av utvalget og TV-guiden, og strømmene du ser på. Leverandøren behandler dette etter sine egne vilkår.
- **Til adresser du selv oppgir** (spilleliste og TV-guide).
- **Ingenting til Nyvy** eller noen andre: ingen statistikk, ingen reklame, ingen sporing.

## Dette nettstedet

Nettstedet ligger på GitHub Pages og bruker ingen informasjonskapsler eller analyseverktøy. GitHub kan logge besøk i henhold til [GitHubs personvernerklæring](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Innhold

Nyvy inneholder ingen TV-kanaler, filmer eller serier, og selger ingen abonnementer. Alt du ser, kommer fra din egen leverandør.
